about the site.

à propos du site.

The first site I ever made (officially with a domain and everything) was hosted on hylton.onl, mainly because I wanted a cool custom email address. I bought the domain on Porkbun and used email routing with Cloudflare to set up a free email (which just forwarded to my main Gmail account). One day, I realized that instead of just using the domain to route emails, I could also use it to make a website. That is how leo.hylton.onl came to be, it was a site that required a PIN to access a secret page. Over time, after showing the website to friends, I kept adding features until it turned into a sort of "enter a word to get an image or video" platform. A little while later, while sorting through some old things, I found an Arduino Uno R3 kit. I messed around with it using the Arduino IDE and various tutorials to display random text and animations, eventually using Python and the Arduino to build a hardware monitor that displays my CPU and RAM usage. Then I had the idea to use my website to let friends display messages on it. Since I was (and still am) using GitHub Pages to host all my sites, it took a bit of research and tinkering. I ended up using Cloudflare Workers to update a txt file whenever a message was submitted via msg.hylton.onl. I then modified my Python code to detect when that text file was updated, fetch the new text, and display it on the Arduino. This was a challenging yet incredibly fun project to build and use

Le premier site que j'ai créé (officiellement avec un nom de domaine et tout le reste) était hébergé sur hylton.onl, principalement parce que je voulais une adresse email personnalisée stylée. J'ai acheté le domaine sur Porkbun et j'ai utilisé le routage d'emails de Cloudflare pour avoir une adresse gratuite (qui redirigeait simplement vers mon compte Gmail principal). Un jour, je me suis rendu compte qu'au lieu d'utiliser le domaine uniquement pour rediriger des emails, je pouvais aussi m'en servir pour faire un site. C'est ainsi que leo.hylton.onl est créé, c'était un site qui nécessitait un code PIN pour accéder à une page secrète. Au fil du temps, après avoir montré le site à des amis, j'ai ajouté de plus en plus de fonctionnalités jusqu'à ce qu'il devienne une sorte de site "entre un mot pour obtenir une image ou une vidéo". J'ai fait quelques essais avec l'IDE Arduino et divers tutoriels pour y afficher du texte ou des animations aléatoires, et j'ai fini par utiliser Python et l'Arduino pour fabriquer un moniteur système qui affiche l'utilisation du CPU et de RAM. Puis, j'ai eu l'idée d'utiliser mon site web pour permettre à mes amis d'y afficher des messages.
